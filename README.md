The single sentence that could have replaced an entire pointless meeting,
built for the [make.fun](https://make.fun) bounty
"The Meeting That Should Have Been One Line".

> The answer is no, the answer was always no, and this meeting was the long way of hearing it.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`, deterministically.
